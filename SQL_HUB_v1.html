📖 How to Use SQL Hub V3
🏠 Home Page
The home page shows all your pinned queries for quick access, plus stats. Click the 📌 icon on any query to pin it.
📂 Module Tabs
Use the module tabs at the top to filter sections. Select a module to see only that section's queries + all utilities below.
🔑 Dynamic Inputs
Type into the input fields above a section. All {{variable}} placeholders update live in the code below. Use the Copy button to copy the query with values substituted.
📌 Pinning Queries
Click the 📌 icon on any query card header to pin it. Pinned queries appear on the Home page for fast access.
🛠 Utilities
Data Formatter — convert lists to SQL IN(...) format, CSV, UPPER/lower.
SQL Differ — paste two SQL queries to highlight differences.
Script Library — store server script file paths and remarks.
Notes — sticky notes with dynamic variable support.
💾 Saving
Click Save in the top bar to download a portable HTML file with all your data embedded. No server needed.
